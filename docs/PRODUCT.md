# Product

Estate agencies already have large volumes of applicant and property data. The problem is that this data is fragmented across conversations, viewings, preferences and CRM events.

Property Intelligence converts operational data into decisions:

- Who should I contact?
- Which property should I recommend?
- How likely is this applicant to convert?
- Why is this applicant a strong match?
- What should the agent do next?

The project is a portfolio/demo prototype and all data is synthetic.
